Basic

Binary: numbers as switches

Key idea: each box is worth double the box to its right: 1, 2, 4, 8, 16... A number is the total of the boxes that are switched on. Position counts from the right, starting at 0, so bit i is worth 2^i.

Click a box to switch it on or off

Decimal to binary: keep dividing by 2

Each remainder is the next bit, filled in from the right. This uses the number from the box above.

02

Basic

AND, OR, XOR: compare column by column

Key idea: these operators look at the two numbers one column at a time, like adding by hand but with no carrying. & needs both 1. | needs at least one 1. ^ needs them to be different.

operator

Click a box to focus its column. Click it again to flip it

Memory trick: AND is strict (both must be 1), OR is relaxed (any 1 is enough), XOR is the odd one out (1 only when the two bits differ).

03

Basic

Shifts and NOT

Key idea: n << k slides every bit k places left and fills with 0s, which multiplies by 2^k. n >> k slides right and the last k bits fall off, which divides by 2^k and drops the remainder.

04

Core

The 4 core moves on bit i

Key idea: build a mask with only bit i switched on, 1 << i. Then pick the operator: & to check, | to set, & ~ to clear, ^ to toggle. Every advanced trick is built from these four.

move
column i, the only one that mattersbit is 1
MoveCodeWhy it works
Checkn & (1 << i)AND with a mask wipes every other column, so only bit i survives. Non-zero means it was 1.
Setn | (1 << i)OR with 1 always gives 1. OR with 0 leaves the other bits as they were.
Clearn & ~(1 << i)~mask is all 1s except column i. AND keeps everything except bit i, which becomes 0.
Togglen ^ (1 << i)XOR with 1 flips a bit. XOR with 0 leaves it alone.
05

Core

The n & (n − 1) family of tricks

Key idea: subtracting 1 flips the lowest 1 to 0 and turns every 0 below it into 1. AND-ing with the original wipes all of those out, so n & (n − 1) removes the lowest set bit.

06

Advanced

XOR magic: pairs cancel out

Key idea: a ^ a = 0 and a ^ 0 = a, and order doesn't matter. So if you XOR a whole list, every number that appears twice cancels itself, and only the single one survives.

Interview problem: this is exactly LeetCode 136, Single Number. It uses no extra memory, just one variable.

07

Advanced

Bitmasks: every subset from a counter

Key idea: for each item there are two choices, take it (1) or skip it (0). With n items, every number from 0 to 2^n − 1 is one way of choosing. Bit i = 1 means "take arr[i]".

Connect it: inside the loop, mask & (1 << i) is the Check move from lesson 04. Advanced problems are the basic moves used in a loop.
