01

Basic

Boxes and index numbers

Key idea: a list is a row of boxes. Each box has a number called its index, and counting starts at 0, not 1.

Remember: the first box is arr[0] and the last box is arr[len(arr) - 1], which you can also write as arr[-1]. Asking for a box that doesn't exist gives IndexError.

Slicing: taking a piece

Key idea: arr[start:stop:step] walks from start and stops before stop. Leave a field empty to use Python's default.

04

Core

Prefix sum: running total from the left

Key idea: prefix[i] is the sum of arr[0] up to arr[i]. Build each one from the one before it: prefix[i] = prefix[i-1] + arr[i].

boxes added so far box being added now previous total we reuse value just computed

The superpower: any range sum in one subtraction

Put a 0 in front to get P. Then P[k] means "sum of the first k boxes", and the sum of arr[l..r] is P[r+1] − P[l]. Move the sliders.

the range you want P[r+1]: everything up to r P[l]: the part before l, which you throw away
05

Core

Suffix sum: running total from the right

Key idea: the mirror image of prefix. suffix[i] is the sum from arr[i] to the end, so you fill it walking backwards: suffix[i] = suffix[i+1] + arr[i].

boxes added so far box being added now previous total we reuse value just computed
06

Advanced

Product of array except self

Key idea: cover one box. Everything left over is a left group and a right group. So answer[i] = left[i] × right[i], where left is a prefix product and right is a suffix product.

covered box (left out) numbers on the left numbers on the right value we reuse value just computed

Why 1 for "nothing"? Multiplying by 1 changes nothing, the same way adding 0 changes nothing. So the empty left side of box 0 and the empty right side of the last box both count as 1.

Key idea: walk left to right with a running sum called current. If the old running sum is negative it can only drag you down, so throw it away and start fresh. Keep the biggest value you ever see in best.
